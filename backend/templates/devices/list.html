Log Perintah Live tap/swipe/type/key/open + latensi ADB (ms). Hijau=OK, merah=GAGAL.
Belum ada perintah. Klik / geser gambar HP untuk menguji.

Cara baca: tap 192.168... (360,800) → 45ms OK = GUI→server→HP sukses 45ms. Bila GAGAL = pesan error ADB tampil. Bila ms > 2000 = latensi WiFi/ADB tinggi, HP terasa lambat walau perintah sampai.

Bantuan (klik bila HP tak muncul / gagal)
  • HP + PC satu WiFi. Di PC: adb connect IP:PORT.
  • Redmi/MIUI: aktifkan USB debugging + Install via USB + USB debugging (Security settings), ketuk Allow saat popup muncul. Bila tap/swipe/tombol merah INJECT_EVENTS tapi buka-URL hijau: itu persis gejala izin ini belum ON — aktifkan di Setelan > Opsi Pengembang (login akun Mi bila diminta), lalu di PC adb disconnect + adb connect IP:PORT ulang.
  • Tombol Bebaskan Macet = selesaikan sesi nyangkut + kembalikan HP ke idle (aman).
  • Hasil uji tercatat: klik Runs / Laporan setelah uji selesai.
